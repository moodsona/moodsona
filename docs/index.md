# moodsona documentation

moodsona simulates emotional users (personas) over several days to test AI
companion chatbots. Start with the [README](../README.md) for installation and
a quickstart.

- [Method](METHOD.md): how the simulator works (hidden state, the turn loop,
  day memory), how it relates to prior research, limitations and ethical notes.
- [Writing a persona](personas.md): field-by-field guide to the persona
  format, how to design reaction rules, how to test and submit a persona.
- [Persona ideas](persona-ideas.md): 20 short briefs to turn into a first persona.
- [Contributing](../CONTRIBUTING.md): development setup, commit rules, DCO,
  AI-assisted contributions.
